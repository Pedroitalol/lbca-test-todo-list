# API TbcaTest
API para teste de seleção para a empresa 

## Atividade 01
Requisitos Técnicos
1. Gerenciamento de Tarefas (CRUD)
A API deve expor endpoints RESTful para gerenciar as tarefas com os seguintes campos:
Id (Identificador único)
Titulo (Obrigatório, máximo 100 caracteres)
Descricao (Opcional)
DataVencimento (Obrigatório, deve ser uma data futura)
Status (Pendente, Em Andamento, Concluída)
Prioridade (Baixa, Média, Alta)
Nota: O endpoint de listagem de tarefas deve, obrigatoriamente, possuir suporte a paginação.
